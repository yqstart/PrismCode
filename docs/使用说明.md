# Prism Code 使用说明

## 快速开始

1. 启动应用：`pnpm tauri:dev`（窗口标题 **Prism Code Dev**，与已安装正式版可同时运行）
2. 使用 **⌘O / Ctrl+O** 或欢迎页按钮打开本地文件夹
3. 在资源管理器中点击文件即可编辑

## 外部打开与命令行

Prism Code 的 Tauri 可执行文件同时提供 `prismcode` 命令行入口。发布版应用内的
可执行文件位于：

```text
/Applications/Prism Code.app/Contents/MacOS/prismcode
```

将该文件安装到 `PATH` 后，可以从终端或其它开发工具打开文件和目录：

```bash
prismcode src/main.ts
prismcode src/main.ts:42:10
prismcode --goto README.md:8:1
prismcode .
```

`--version` 和 `--help` 可用于检测 CLI 是否可用。桌面应用启用单实例转发，
重复执行命令时会把路径送到已打开的 Prism Code 窗口，不会创建孤立的第二个实例。
macOS 文件关联也已随安装包声明，Finder 或 Launch Services 传入的文件会走同一套
外部打开流程。

外部打开按工作区归属分流：

- 已在当前窗口工作区内的文件：留在本窗口打开并定位（带行号时直接跳转）；
- 工作区外的文件：在新窗口以**单文件模式**（light）打开，不再把文件所在目录当成项目；
- 目录：与当前工作区相同时忽略，不同则新开窗口；无工作区时首个目录留在本窗口；
- 无工作区（欢迎页 / light 窗口）时，文件直接在当前窗口打开，窗口随即进入单文件模式。

**单文件模式（light）**：窗口不绑定任何工作区，只承载外部打开的独立文件。

- 编辑器、类型服务、格式化、图片预览按文件所在目录取读写作用域，编辑与保存能力与项目内一致；
- 不显示资源树、不加载 Git、不写入工作区会话快照；窗口头项目 widget 与状态栏显示当前文件名与路径，
  资源管理器提示「单文件模式」；
- 窗口重新获得焦点时校验打开文件的磁盘内容，其它编辑器 / 终端的改动会被发现并重载；
- 关闭窗口前会先确认未保存的独立文件；应用退出（⌘Q）时按自动保存设置先落盘，
  关闭自动保存时才弹确认，避免静默丢改；
- 打开文件夹（⌘O 或资源管理器中的「打开文件夹」）即切换到项目模式，light 标签会先确认再清空。

## 资源管理器

- **文件图标**：对齐 VS Code Material Icon Theme（按文件名 / 扩展名 / 常见文件夹名）
- **刷新**：Project 工具窗口面板头的刷新按钮（⌘R）；打开文件夹后自动监听外部文件变更；窗口重新获得焦点时也会同步
- **定位当前文件**：十字准星按钮，或 **⌥F1**；展开祖先目录、滚动并高亮目标
- **按名称查找文件**：工具窗口内不再有过滤框，改用 **⇧⇧（Search Everywhere）/ ⌘⇧O** 按名称检索全项目文件（见「搜索」章节）
- **折叠全部**：收起除根目录外的展开节点
- **外部改动**：磁盘文件被外部修改时，干净标签自动重载；有未保存更改时会询问是否覆盖
- **右键菜单**：新建文件 / 文件夹、重命名、删除、复制 / 剪切 / 粘贴、复制绝对 / 相对路径、格式化文档
- **复制 / 剪切 / 粘贴**：资源树聚焦时 `⌘/Ctrl+C/X/V` 可用；选中文件夹粘贴进该文件夹，选中文件粘贴进其父目录。从 Finder / 文件资源管理器复制的文件可在树中直接粘贴（重名自动加 `-copyN` 后缀）；内部复制优先，内部剪贴板为空时才读系统剪贴板
- **拖拽移动**：按住拖到目标文件夹移动文件（pointer 拖放实现）
- Project 工具窗口打开时，切换编辑标签会在树中自动跟随定位；文件名旁有 Git 状态色点

## 编辑器

- **语法高亮**：JS / TS / Vue / HTML / CSS / SCSS / Sass / Less / JSON / Markdown / YAML / XML / SVG / Env
- **代码补全**：JS/TS/JSX/TSX 使用内嵌 TypeScript 类型服务（成员、自动导入、签名帮助）；Vue script 使用虚拟 TS，template 注入 `<script setup>` 绑定；HTML/CSS 使用同源语言服务；失败时回退关键字、片段与文档词
- **诊断**：JS/TS/Vue script 语义诊断、JSON 解析错误、`.env` 重复 key 本地校验，lint gutter 提示
- **格式化**：WebStorm 键位 **⌘⌥L / Ctrl+Alt+L** 会按“有单一选区则只格式化选区，否则格式化全文”执行；**⌥⇧F** 与菜单 / 右键仍可格式化全文，**⌘K ⌘F** 保留为选区格式化兼容入口。内置 Prettier 引擎开箱即用（零配置、离线，覆盖 JS/TS/JSON/CSS/SCSS/Less/HTML/Vue/Markdown/YAML/GraphQL）；项目已安装 prettier 时优先使用项目版本，内置兜底也会从当前文件目录向项目根查找最近的 JSON 形式 Prettier 配置
- **诊断导航**：lint gutter 与悬浮提示保留不变；F8 / Shift+F8 在诊断之间前后移动；问题清单集中在底部 **Problems** 工具窗口（**⌘6** 打开，支持全部 / 错误 / 警告过滤，点击条目跳转）
- **查找替换**：⌘F / ⌘⌥F，支持区分大小写、正则，替换有预览与确认
- **跳转 / hover**：带强调色下划线的引用仅用于提示可导航目标，普通鼠标点击只移动光标；使用 ⌘B / ⌘Enter / F12 触发声明跳转。JS/TS/Vue script 的 class、函数和一般符号使用 TypeScript 声明与悬浮信息，Vue 模板组件支持 PascalCase / kebab-case 及 `defineAsyncComponent`；HTML/Vue class 会跳到同文件或外置 CSS 选择器。跳转后目标文本、目标行和行号会短暂显示强调色，便于确认落点；`@/*` 按 `src/*` 解析，本地命名 import 上的跳转走轻量直达路径并落到真实导出声明，只有光标位于路径字符串时才打开模块文件；⌘[ 后退、⌘] 前进
- **引用 / 重命名**：Shift+F12 打开引用结果面板，F2 显示影响文件后执行跨文件重命名；未打开的 JS/TS 文件也会直接更新
- **Markdown 预览**：打开 `.md` 默认预览（可切源码），基于 marked；预览内容可**选中并复制**（⌘/Ctrl+C）；预览态支持 ⌘/Ctrl+F 只读查找（区分大小写 / 正则 / 全词，Enter / ⌘G 导航，Esc 关闭）
- **图片预览**：图片 / SVG 双击在编辑区预览
- **自动保存**：默认开启（1 秒防抖），设置中可关闭
- **会话恢复**：按工作区恢复上次打开的标签、活动文件、光标、固定状态；符合条件的未保存缓冲区也会恢复，磁盘已变化时不覆盖磁盘版本
- 有 Git 变更时，编辑区右键可「显示 Diff / 回滚变更」

## 终端（底部 Terminal 工具窗口）

终端位于**底部工具窗口区**（Terminal / Problems / Debug 三选一显示）：区域在**编辑器列下方**展开（只占编辑区列，左侧工具窗口列保持整列全高），顶缘可拖拽调高，与编辑器上下分栏并存。

### 本地终端

1. 点击**工具窗口条下组的终端图标**（Problems 与 Debug 之间），或按 **⌘/Ctrl+J** / **⌥/Alt+F12**，或资源树右键选择「在终端中打开」（右键**文件**进入其所在文件夹、右键**文件夹**进入该文件夹，自动落一个终端到目标目录）
2. Terminal 工具窗口在编辑器下方展开，可多开终端（窗口内顶行的子标签切换）；终端标签显示 **shell 名**（zsh / bash / powershell），同 shell 多开时自动加序号（如 `zsh (2)`）；拖动区域顶缘的分隔条可调整高度，高度自动记忆；**新建终端自动聚焦**，打开即可直接输入
3. 再次按 **⌘/Ctrl+J**、点击顶行右侧 **▼** 或工具窗口标题行的 **✕** 收起，**会话与 PTY 保持运行**；再按一次恢复
4. 切换文件标签 / 查看 Git Log / SSH 时工具窗口保持展开，互不干扰；点击顶行终端子标签的 **×** 才真正结束该终端会话

**Scripts 快捷执行**：工具窗口条下组的 **Package** 图标弹出脚本弹层，每条脚本前可**勾选**，勾选的脚本以芯片形式出现在 Terminal 工具窗口顶行右侧，点击即在当前终端执行（`pnpm/npm/yarn/bun run …`）；若当前终端**正在运行任务**（如 `npm run dev`），自动**新开一个终端**执行，避免命令叠加进忙碌终端；勾选状态**按项目记忆**，取消勾选后芯片消失。

窗口头 **Run widget** 的配置下拉把 Java / Maven / Spring 运行配置与 **npm 脚本**并列：选中脚本后点 **▶ 运行**，同样在终端执行（终端忙时自动新开）；**🐞 调试**只适用于 Java 运行配置，选中 npm 脚本时该按钮为禁用态。

### SSH 远程

1. 点击**工具窗口条上组的 SSH 图标**（或编辑区右侧固定的「SSH」标签）进入主机列表
2. 主机列表：**添加主机 / 仅保存**写入主机列表；可勾选「记住密码」（存于 `~/.prismcode/ssh-credentials.json`）；首次连接未知主机需确认指纹（TOFU）
3. 连接后即进入**远程终端**：与本地终端互不干扰；输入与本地终端一致（Ctrl+C / 复制粘贴等通用快捷键）

### 切换项目

两个入口都能切换项目：

- **窗口头项目 widget**（项目名 ▾）：**复制路径** / **打开文件夹** / **最近打开**（点选最近项目，在本窗口切换）；
- **Project 工具窗口树首行的项目根节点**：点名称打开项目菜单 —— 最上方 **打开新项目…**，下方最近项目列表，选择后提示 **在本窗口打开** 或 **在新窗口打开**。

切换项目会强制关闭 SSH 远程连接并重建本地终端（cwd = 新项目根）。

## Java 工程（运行 / Spring / 调试）

底部工具窗口区有三个工具窗口：**Terminal（终端）/ Problems（问题）/ Debug（调试）**；Java 相关的运行与调试都在这里落地，语言智能（补全、诊断、跳转、引用、重命名、格式化）由随包分发的 JDTLS 提供，离线可用。状态栏右侧的 **Java 状态**按钮（当前文件为 Java 或语言服务未停止时出现）可启动 / 停止语言服务、重建索引、查看日志、打开设置，以及打开 **Spring 端点**。

### 运行配置芯片

打开 Maven / Gradle 项目后，Terminal 工具窗口顶行会出现按模块分组的运行芯片：

| 芯片 | 命令 |
|---|---|
| 测试 | `mvn -B -ntp [-pl 模块] test`（当前文件属于该模块时自动加 `-Dtest=类名`） |
| 打包 | `mvn -B -ntp [-pl 模块] -DskipTests package` |
| 清理 | `mvn -B -ntp [-pl 模块] clean` |
| 运行 | 模块声明了 `spring-boot-maven-plugin` 时为 `spring-boot:run`（Gradle 为 `bootRun` / `quarkusDev` / `run`） |
| 调试 | 与「运行」同一条命令，但先注入 JDWP 并挂起等待调试器 |

- 项目里存在 `mvnw` / `gradlew` 时优先用包装器；
- 芯片执行沿用终端忙闲判定：当前终端在忙就自动新开一个；
- `packaging=pom` 的聚合模块不产出可运行配置（不会出现在芯片里）；
- 没有再开终端时，「运行当前文件」芯片会直接执行 `java <文件>`（PATH 上没有 `java` 时用随包 JRE）；
- 覆盖运行配置：在项目里建 `<项目>/.prismcode/run/project.json`，按配置 `id` 覆盖字段，例如

```json
{
  "configurations": [
    { "id": "maven.module:app:test", "args": ["-B", "-pl", "app", "verify"] }
  ]
}
```

### Spring 端点与配置

- **端点列表**：状态栏 Java 菜单 →「Spring 端点」，以只读标签列出 `@RequestMapping` / `@GetMapping` 等项目内声明的 HTTP 路由（`METHOD  /route  文件:行`）；
- **配置补全**：编辑 `application*.properties` / `application*.yml` 时提示配置键（项目内已有的键 + 依赖 jar 的 `spring-configuration-metadata.json`）；
- **诊断**：`@Value("${...}")` 引用的键找不到时给出诊断（全大写下划线的键按环境变量处理，不报）。

### 调试

1. 在 Java 文件**行号左侧**点击即增删断点（红点）；
2. 点模块的**调试**芯片：底部工具窗口区自动切到「调试」工具窗口，目标以 `suspend=y` 启动并挂起，JDTLS 内的调试适配器 attach 之后自动恢复运行；
3. 命中断点后：线程 / 调用栈 / 变量三栏联动，调用栈双击可跳到源码位置，顶部按钮依次为**继续 / 暂停 / 单步跳过 / 单步进入 / 单步跳出 / 停止**；
4. 30 秒连不上调试器会打断目标并提示重试；收起底部工具窗口区、关闭窗口或退出应用都会结束调试会话（调试器不常驻）。

> 调试适配器（java-debug）随安装包分发。开发时先执行 `node scripts/prepare-debug-adapter.mjs`；也可以在**设置 → Java → 调试适配器路径**里指向自备的插件 jar（或其所在目录），或用环境变量 `PRISMCODE_JAVA_DEBUG_JAR` / `PRISMCODE_JAVA_DEBUG_HOME` 覆盖。

## 搜索（对照 WebStorm）

左侧工具窗口条不放置搜索入口（对齐 WebStorm），通过快捷键或窗口头右侧的搜索按钮唤起：

### 最近文件与按名称跳转

- **⌘/Ctrl+E**：对应 WebStorm「Recent Files」，空查询直接按最近访问顺序显示仍然存在的文件，关闭标签后仍保留最近记录。
- **⌘⇧O（macOS）/ Ctrl+Shift+N（Windows / Linux）**：对应 WebStorm「Go to File」；`⌘/Ctrl+P` 作为兼容入口。
- 支持文件名、路径片段和 CamelHump 子序列模糊匹配；可在查询末尾追加 `:行[:列]`，例如 `CME:42:3`。
- ↑/↓、Home/End、PageUp/PageDown 选择，Enter 打开；高亮项自动滚入可视区。

### 在文件中查找（⌘⇧F）

对应 WebStorm「Find in Files」：居中弹层，支持

- 文本查找 / 区分大小写
- 文件掩码（如 `ts,vue,md`）
- 替换预览与全部替换确认
- 结果列表 `路径:行号`，Enter 打开并关闭；⌘Enter 打开并保持弹层

## Git（对照 VS Code Source Control + Git Graph）

- **Commit（左侧）**：⌘K；「暂存的更改 / 更改」分组；单 / 批量暂存与取消；行内暂存·取消暂存·回滚；点文件在编辑区打开 Diff；Commit / Commit and Push（提交已暂存）；Amend 复选
- **变更状态字母**：`M` 已修改 · `U` 未跟踪 · `D` 已删除 · `C` 冲突；悬停可看说明
- **回滚**：更改列表行内 / 右键「回滚…」；编辑区对有变更的文件右键「回滚变更…」；未跟踪文件回滚会删除；回滚后编辑器内容会同步重载
- **工具栏图标**：Update Project（Fetch 后合并 / 变基）· Fetch（只下载）· Pull · Push · Stash 贮藏（计数徽章，可展开 apply / pop / drop）
- **Update / Fetch / Pull / Push**：Push 与 Update 为对话框（Merge / Rebase、Force push 需确认）
- **Branches**：窗口头 **VCS widget**（分支名 ▾）→ 本地 / 远程弹层；右键含 Checkout、New Branch、Rename、Delete（本地 / 远程）、Merge into current、Rebase current onto、交互式 Rebase、Compare with current、Set upstream、Copy
- **Git Log（编辑区标签，与普通文件标签一致）**：工具窗口条上组的 **Git Log 图标**打开后先完整加载，再默认选中 HEAD / 最新提交；真实多车道 Graph 展示本地 / 远程 / 标签 / 贮藏拓扑，右侧固定显示提交正文、父提交和变更文件。↑/↓ 逐条选择，← 进入父提交，→ 返回子提交；只有 Git Log 自身聚焦时才响应，终端与输入框方向键不再被截获。分支范围支持全部 / 当前 / 多选，另有远程、标签、贮藏开关；文本过滤、自动加载更多、⌘/Ctrl+H 定位 HEAD、⌘/Ctrl+S 定位贮藏、可见列设置；Cmd/Ctrl 点击两提交进入比较；文件支持 Diff、打开当前版本、复制路径、代码评审勾选；提交右键 Checkout / New Branch / Create Tag / Copy / Show Diff / Compare with HEAD / Cherry-pick / Revert / 交互式 Rebase / Reset（soft/mixed/hard）；分支 / 标签引用右键 Checkout / Merge / Rebase / Compare / Rename / Delete / Push Tag。未提交更改不混入历史首行，统一在 Commit 面板处理，Git Log 工具栏的“未提交更改”按钮可直接切换过去
- **交互式 Rebase**：提交列表 pick / reword / squash / fix / drop + 拖拽排序；冲突时 Commit 横幅 Continue / Skip / Abort
- **登录**：HTTPS 需认证时弹账号密码；勾选「记住」写入 `~/.prismcode/git-credentials.json`（并尽力同步系统 Git 凭据）
- **冲突**：Commit 列表冲突横幅一键批量接受本地 / 远程；分栏合并（CompareView：左右双栏，prev / next 冲突导航，填入本地 / 远程 / Base，保留任一侧或手动编辑保存）；状态栏冲突数可点跳转

## 主题与语言

设置 → 编辑器 → 外观主题，六套可选（默认 **IntelliJ Dark**）：

- IntelliJ Dark（IntelliJ IDEA 2026.2 官方 New UI Dark 色板：`#1E1F22` 底、Blue6 强调，语法色取自官方 Dark scheme）
- IntelliJ Light（IntelliJ IDEA 官方 New UI Light 色板：`#F7F8FA` / 白色编辑区，语法色取自官方 Light scheme）
- Prism Dark（深色，紫强调）
- Prism Light（浅色，蓝强调）
- Prism Midnight（深蓝，青蓝强调）
- Prism Cyberpunk（霓虹，青强调）

IntelliJ Dark / Light 的 UI 与编辑器配色均直接取自本机 IntelliJ IDEA 安装的官方主题定义（`expUI_dark/light.theme.json` 与 `expUI_dark/lightScheme.xml`），布局细节（编辑器标签 4px 圆角下划线、透明 hover、状态栏信息分区、工具窗口选中块）按 IDEA New UI 对齐。

切换 UI 主题时编辑区代码高亮**同步切换**。状态栏主题名也可快捷切换（点击弹菜单，右键循环）。

设置左侧底部可切换**界面语言**：中文 / English；切换后窗口头、工具窗口条、工具窗口、编辑区、Git、搜索、终端、对话框以及 **macOS 顶部菜单栏**会同步变更，**无需重启**。

设置 → 编辑器还可配置：

- **自动保存**（默认开，可调延迟）/ **保存时格式化**（默认关）
- **ESLint**（默认关闭；调用当前项目本地依赖，需已 `npm/pnpm install`）/ **Prettier**（默认开启；内置引擎零依赖，项目已装时自动优先项目版本）
- **移动文件时更新 import**（三态：询问 / 自动 / 关闭）

## 更新

- 设置 → 系统 → **启动时自动检查**（默认开）：启动约 4 秒后静默检查，有新版本时右上角出现更新徽章
- **检查更新**：手动检查，确认后下载安装并重启
- 更新包来源：GitHub Release（`latest.json`），需签名校验
