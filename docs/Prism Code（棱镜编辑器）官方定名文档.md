# Prism Code 官方定名文档

Prism Code（棱镜编辑器），是基于 Tauri + Vue3 构建的**轻量化、高颜值、全语法专业桌面代码编辑器**。产品采用 VS Code 经典灵活布局、自主设计的极简低饱和视觉 UI、WebStorm 标准的文件检索与 Git 管理体系，覆盖全主流开发语法的智能编辑能力，兼顾极致性能、极简颜值与专业编码体验。本文档为项目官方唯一品牌定名规范，所有项目文档、源码、产品展示统一使用该名称口径。

## 一、品牌官方释义

**Prism Code** 为项目唯一官方定名，中文名 **棱镜编辑器**。

**Prism（棱镜）** 寓意：将复杂代码「折射」为清晰可读的光谱——语法高亮、类型解析、诊断与导航如同分光，让结构一目了然；同时呼应产品轻量、精准、专业的气质。

此前曾用名 Miro Code（米罗编辑器），因与 Miro.com 看板产品易混淆，自 2026 年起全面更名为 Prism Code。

## 二、品牌核心适配定位（官方统一口径）

**唯一官方定名：Prism Code（棱镜编辑器）**

产品定位统一口径：**高颜值极简轻量化、全语法全覆盖、类 WebStorm 专业功能、VS Code 流畅布局的跨平台桌面代码编辑器**。

核心品牌优势（对外/文档/源码统一表述）：

- **轻量高性能**：基于 Tauri + Vue3 开发，秒启动、低内存占用、跨平台流畅运行。
- **极简高颜值 UI**：极简低饱和视觉设计，沉浸式编辑界面。
- **专业级功能**：资源管理器、全局检索、Git 版本管理对标 WebStorm 交互逻辑。
- **全语法智能编辑**：主流前端、配置、文档语法统一支持高亮、折叠、校验、补全、引用跳转。
- **高辨识度品牌**：Prism Code 与主流编辑器无重名冲突，可长期品牌沉淀。

## 三、全域命名规范（强制统一）

所有项目相关资料、源码注释、文档、产品展示、介绍文案，统一执行以下口径，禁止混用旧名 Miro Code / MiroCode / mirocode：

| 场景 | 规范 |
| --- | --- |
| 官方全称 | **Prism Code** |
| 中文名 | **棱镜编辑器** |
| 英文简称 | **PrismCode**（文件夹、仓库名、包名） |
| npm / 包名 | `prismcode` |
| Rust crate | `prismcode` / `prismcode_lib` |
| CLI 命令 | `prismcode` |
| Bundle ID | `com.prismcode.app`（Dev：`com.prismcode.app.dev`） |
| 用户数据目录 | `~/.prismcode/` |
| 默认深色主题 ID | `prism-dark` |
| GitHub 仓库 | `yqstart/PrismCode` |

## 四、与第三方品牌区分

- **Prism Code** 与 [Miro.com](https://miro.com)（在线协作看板）无任何关联。
- 更名前曾用 Miro Code；历史 Release 与旧安装包仍可能显示旧名，新发行一律使用 Prism Code。
